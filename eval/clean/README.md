# CLEAN EC accuracy

This folder contains:

1. A helper script to run [CLEAN](https://github.com/tttianhao/CLEAN) on one
   FASTA generated by Rexzyme (`CLEAN_infer_fasta.py`).
2. A plotting script to compute and visualize EC accuracy at levels 1, 1-2,
   1-3, and 1-4 for the five small `generation_*` groups
   (`plot_clean_ec_accuracy.py`).

CLEAN itself is external and must be installed separately.

## Prerequisites

From the root of this repository, create/activate a Python environment and
install Rexzyme dependencies:

```bash
cd /path/to/Rexzyme_nuria
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-eval.txt
```

Then install CLEAN by following its official instructions in the
[CLEAN repository](https://github.com/tttianhao/CLEAN).

## 1) Run CLEAN on generated FASTAs

Clone CLEAN:

```bash
git clone https://github.com/tttianhao/CLEAN.git
```

Run CLEAN inference from `CLEAN/app`. Pass the FASTA path with
`--input-fasta`; the script copies it into `data/inputs/`:

```bash
cd /path/to/CLEAN/app
python /path/to/Rexzyme_nuria/eval/clean/CLEAN_infer_fasta.py \
  --input-fasta /path/to/Rexzyme_nuria/data/generated/generation_most/output_topk100_file_1.fasta
```

Notes:

- `--input-fasta` / `--input` is the generated FASTA on disk.
- `-d` still accepts a CLEAN-relative basename such as `output_topk100_file_1`.
- The script runs CLEAN with `train_data=split100`.
- Output predictions are written by CLEAN to:
  `results/inputs/output_topk100_file_1.csv`.


## 2) Plot EC accuracy

[`plot_clean_ec_accuracy.py`](plot_clean_ec_accuracy.py) compares CLEAN
prediction CSVs to reference EC tables. Pass one CSV and one TSV per group,
then `--output` for the plot prefix:

```bash
python eval/clean/plot_clean_ec_accuracy.py \
  --most-csv most_predictions.csv \
  --most-ec data/extended_reaction_information/generation_most/generation_most.tsv \
  --middle-csv middle_predictions.csv \
  --middle-ec data/extended_reaction_information/generation_middle/generation_middle.tsv \
  --output clean_ec_accuracy
```

Group flags: `--most-csv` / `--most-ec`, `--middle-csv` / `--middle-ec`,
`--low-csv` / `--low-ec`, `--val-com-csv` / `--val-com-ec`,
`--val-dif-csv` / `--val-dif-ec`.

Reference TSV format (three columns: `smiles`, `rhea_id`, `ec`):
[generation_most.tsv](../../data/extended_reaction_information/generation_most/generation_most.tsv).
